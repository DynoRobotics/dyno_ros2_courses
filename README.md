# Dyno Robotics ROS2 Courses

## Dynoturtle
Dynoturtle is a simple multirobot simulation environment based on the standard ROS2 turtlebot tutorial. 

For useful commands and how to start the Dynoturtle simulator, see [day1_command_cheat_sheet.txt](./docs/session1/day1_command_cheat_sheet.txt) in `./docs/session1/`.

## Dynobot
Dynobot is a more advanced simulation environment using the Gazebo physics simulator and a more advanced robot model definition, containing a lidar and using a differential drive motion model to be able to drive around the world.

For useful commands and how to start the Dynobot robot with the Gazebo physics simulator, see [day2_command_sheet_cheat.txt](./docs/session2/day2_command_cheat_sheet.txt) in `./docs/session2/`

### Manual Steering With Controller
If a Logitech F710 controller is plugged in while starting the container, manual control will be possible by pressing the `LB` and steering with the left joystick.

> Note: Make sure that the mode switch on the back of the controller is set to `D`.
