# Bundled ROS2 Messages

This directory contains auto-generated ROS2 message and service definitions bundled with `ros2_zenoh_python` for testing and basic usage.

## What's Included

- **builtin_interfaces**: Time, Duration
- **std_msgs**: String, Int32, Header, and all standard message types
- **geometry_msgs**: Twist, Pose, Point, Quaternion, Vector3, and all geometry types
- **example_interfaces**: AddTwoInts service and example message types

## Size

- **1.8 MB** (113 Python files)
- Includes only essential packages for tests and examples

## Usage

```python
from ros2_zenoh_python._bundled_msgs.std_msgs.msg import String
from ros2_zenoh_python._bundled_msgs.example_interfaces.srv import AddTwoInts
from ros2_zenoh_python._bundled_msgs.geometry_msgs.msg import Twist
```

## Generating More Interfaces

If you need additional ROS2 interfaces, use the `ros2_interface_generator`:

```bash
cd /path/to/ros2_interface_generator
python3 -m ros2_interface_generator.generator python /path/to/output \
    --packages sensor_msgs nav_msgs action_msgs
```

Or use the convenience script:

```bash
# Generate essential packages
./bin/generate-standard-interfaces essential my_interfaces

# Generate common packages
./bin/generate-standard-interfaces common my_interfaces

# Generate all packages
./bin/generate-standard-interfaces all my_interfaces
```

## Type Hashes

All bundled messages include correct RIHS01 type hashes for full interoperability with:
- `rclpy` (using `rmw_zenoh_cpp`)
- `ros2 CLI` tools
- Other ROS2 nodes using Zenoh middleware

## Auto-Generated

⚠️ **Do not edit manually!** These files are auto-generated by `ros2_interface_generator`.

To regenerate:

```bash
cd /path/to/ros2_zenoh_python/ros2_zenoh_python
rm -rf _bundled_msgs
python3 << 'EOF'
import sys
from pathlib import Path
sys.path.insert(0, str(Path('../../../ros2_interface_generator')))
from ros2_interface_generator import generate

generate(
    language='python',
    packages=['builtin_interfaces', 'std_msgs', 'geometry_msgs', 'example_interfaces'],
    output_path='_bundled_msgs_temp'
)

import shutil
shutil.move('_bundled_msgs_temp/ros2_interfaces_py', '_bundled_msgs')
shutil.rmtree('_bundled_msgs_temp')
EOF
```
