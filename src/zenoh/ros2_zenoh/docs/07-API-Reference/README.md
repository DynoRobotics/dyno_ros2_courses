## Generation

### Manual

```bash
# Generate all API docs
just api-docs

# Or run directly
python tools/generate_api_docs.py
```

### Automatic

API docs are regenerated:
- On every commit (pre-commit hook)
- On every PR (CI)
- On release builds

## Source of Truth

**Code is the source of truth**, not these docs.

- Docstrings in source files are canonical
- These docs are derived representations
- If docs and code disagree, code wins

## Validation

`tools/validate_spec_code_sync.py` checks:
- ✅ Public API matches spec signatures
- ✅ Required methods documented
- ✅ Type hints match spec types
- ✅ Examples in docs are runnable
